# OculusJJ キーボードショートカット一覧

このドキュメントは、現在の OculusJJ で実装されているショートカットキーの一覧です。
これらの設定は Horos (OsiriX) の標準的な挙動に準拠しています。

## 1. 画像操作・編集
| キー | アクション | 備考 |
| :--- | :--- | :--- |
| **H** | 左右反転 (Horizontal Flip) | 表示中の画像を左右にミラーリングします。 |
| **V** | 上下反転 (Vertical Flip) | 表示中の画像を上下にミラーリングします。 |

## 2. スライス移動 (ナビゲーション)
| キー | アクション | 備考 |
| :--- | :--- | :--- |
| **← (左矢印)** | 前の画像へ | 1枚前のスライスを表示します。 |
| **→ (右矢印)** | 次の画像へ | 1枚後のスライスを表示します。 |
| **PageUp** | 10枚戻る | |
| **PageDown** | 10枚進む | |
| **Home** | シリーズの最初へ | |
| **End** | シリーズの最後へ | |

## 3. 表示設定・ズーム
| キー | アクション | 備考 |
| :--- | :--- | :--- |
| **Tab** | アノテーション切替 | なし → 図形のみ → 基本 → 全表示 の順で切り替わります。 |
| **↑ (上矢印)** | ズームイン | 画像を大きく表示します。 |
| **↓ (下矢印)** | ズームアウト | 画像を小さく表示します。 |
| **1** | WL/WW: Brain | 40 / 80 に設定します。 |
| **2** | WL/WW: Bone | 300 / 1500 に設定します。 |
| **3** | WL/WW: Lung | -600 / 1500 に設定します。 |
| **4** | WL/WW: Soft Tissue | 40 / 400 に設定します。 |
| **5** | WL/WW リセット | DICOMタグのデフォルト値に戻します。 |
| **W** | WL/WW ツール選択 | マウスドラッグでWL/WWを調整するモード。 |
| **Z** | ズーム ツール選択 | マウスドラッグで拡大・縮小するモード。 |
| **P** | パン ツール選択 | マウスドラッグで画像を移動するモード。 |
| **M** | 長さ計測 ツール選択 | マウスドラッグで線を引き、距離を測るモード。 |
| **E** | Repulsor ツール選択 | ROIの形状をドラッグで調整するモード。 |
| **T** | テキスト ツール選択 | 画像上に文字を入力するモード。 |
| **S** | セレクター ツール選択 | ROIの選択や移動を行う標準モード。 |

## 4. マウス操作
| 操作 | アクション | 備考 |
| :--- | :--- | :--- |
| **ホイール** | スライス移動 | 同期がONの場合は他ビューも追従します。 |
| **Alt + ホイール** | ズーム | マウスホイールで拡大・縮小を行います。 |
| **Shift + ホイール** | 高速スクロール | 通常より速く (5枚単位) スライスを移動します。 |
| **左ドラッグ** | 現在のツール | W, Z, P, Mキーで選択したツールを実行します。 |
| **右ドラッグ** | WL/WW 調整 | ツールに関わらず、左右で幅、上下でレベルを変更します。 |
| **中ボタンドラッグ** | パンニング | ツールに関わらず、画像を移動します。 |
| **Ctrl + 左ドラッグ** | パンニング | (Windows環境向け) 右クリックのない環境等で使用。 |
| **Alt + 左ドラッグ** | ズーム | ツールに関わらず、画像を拡大・縮小します。 |
| **ダブルクリック** | WL/WW リセット | |

## 5. ROI操作
| 操作 | アクション | 備考 |
| :--- | :--- | :--- |
| **長さ計測 (M)** | 距離測定 | ドラッグで線を引き、離すと確定。mm単位で表示（DICOM Pixel Spacing準拠）。 |
