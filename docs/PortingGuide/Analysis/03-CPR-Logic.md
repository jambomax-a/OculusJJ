# CPR（曲面再構成）ロジック仕様書

## 1. 概要
CPR (Curved Planar Reconstruction) は、3Dボリュームデータ内において、ユーザーが指定した曲線パスに沿って断面を切り出し、それを2D平面に展開して表示する機能である。本ドキュメントでは、その数学的定義と実装フローを定義する。

## 2. CPR処理パイプライン
CPRの生成プロセスは以下の4つのステップで構成される。

$$\text{曲線パスの定義}  →  \text{サンプリング点と局所座標系の生成}  →  \text{3D再サンプリング（補間）}  →  \text{2D展開図への投影}$$

### 2.1 曲線パスの定義 (Path Generation)
ユーザーが指定した制御点 $C_0, C_1, \dots, C_n$ を基に、B-SplineまたはCatmull-Romスプラインを用いて連続的な曲線 $P(t)$ を生成する。
- **パラメータ $t$**: 0から1まで変化する正規化パラメータ。
- **等間隔サンプリング**: 曲線上の弧長（Arc Length）に基づき、一定間隔（例: 0.5mmごと）でサンプリング点 $P_i$ を抽出する。

### 2.2 局所座標系の構築 (Frenet-Serret Frame)
各サンプリング点 $P_i$ において、断面を切り出すための局所基底ベクトルを計算する。

1. **接線ベクトル (Tangent $\vec{T}$)**: 
   $\vec{T}_i = \frac{P'(t_i)}{\|P'(t_i)\|}$ （曲線の進行方向）
2. **法線ベクトル (Normal $\vec{N}$)**: 
   $\vec{T}_i$ に直交するベクトルを定義する。通常、画像の「上方向」を維持するため、世界座標のZ軸 $\vec{k}(0,0,1)$ との外積を用いて計算する。
   $\vec{B}_i = \vec{T}_i \times \vec{k}$ (Bivector)
   $\vec{N}_i = \vec{B}_i \times \vec{T}_i$
3. **断面平面の定義**: $\vec{N}_i$ と $\vec{B}_i$ が成す平面が、その点における断面となる。

### 2.3 3D再サンプリングと補間 (Resampling & Interpolation)
断面平面上の各ピクセル $(u, v)$ について、3Dボリュームデータの輝度値を抽出する。

2. **ボリューム座標への変換**:
   $\mathbf{P}_{world} \xrightarrow{\mathbf{T}} \mathbf{V}_{pos}(x, y, z)$ (ピクセル単位の座標)
3. **三線形補間 (Trilinear Interpolation)**:
   $\mathbf{V}_{pos}$ 周囲の8つのピクセル値を用いて、線形補間により正確な輝度値を算出する。
   - $f(x,y,z) \approx \sum_{i,j,k \in \{0,1\}} w_{ijk} \cdot \text{Value}(x_i, y_j, z_k)$

### 2.4 2D展開図への投影 (Projection)
抽出した輝度値を2D画像のピクセル座標 $(X, Y)$ にマッピングする。

- **X軸 (展開方向)**: 曲線の累積弧長 $L_i = \int_0^{t_i} \|P'(t)\| dt$ を使用する。
- **Y軸 (断面方向)**: 局所座標の $v$（$\vec{N}_i$ 方向）をそのまま使用する。
- **結果**: $Image(X, Y) = \text{interpolated\_value}(L_i, v)$

## 3. 実装上の留意点

### 3.1 パフォーマンス最適化
- **FloatBufferの使用**: ボリュームデータは `java.nio.FloatBuffer` 等のオフヒープメモリに保持し、GCオーバーヘッドを削減する。
- **マルチスレッド処理**: 展開図の各列（各サンプリング点）は独立して計算可能なため、`Parallel Stream` または `ForkJoinPool` を用いて並列化する。
- **LOD (Level of Detail)**: ユーザーがパスを編集している間は、サンプリング間隔を粗くして低解像度でプレビュー表示する。

### 3.2 境界条件の処理
- **ボリューム外アクセス**: サンプリング点がボリューム範囲外に出た場合は、定数（0.0f）を返す。
- **特異点の処理**: 接線ベクトル $\vec{T}$ が Z軸 $\vec{k}$ と平行になった場合、外積がゼロになるため、代替ベクトル（X軸など）を使用して法線を計算する。

## 4. 期待される結果
- 血管などの屈曲した構造が、直線的に展開されて表示される。
- 断面の厚みを調整することで、MIP (Maximum Intensity Projection) のような効果をCPR断面に適用できる。"
