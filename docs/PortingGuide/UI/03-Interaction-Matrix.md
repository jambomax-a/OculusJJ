# UI 操作・インタラクション仕様書 (Java Porting)

## 1. 概要
本ドキュメントは、OculusJJにおける2D/3Dビューアのインタラクション仕様を定義する。特に、HOROS-20240407の操作性を完全再現し、3Dビュー上のカメラ回転、スクリーン整合パニング、リアルタイムWW/WL窓調整を数学的に同期させる操作マトリクスを策定する。

---

## 2. 2D ビューア マウス操作マトリクス

2D DicomImageView における標準操作。

| 操作 | 修飾キー | ツールモード | 実行されるアクション | 備考 |
| :--- | :--- | :--- | :--- | :--- |
| **左ドラッグ** | なし | 任意 | **選択中のツールを実行** | W:WL/WW, Z:Zoom, P:Pan, M:Measure |
| **右ドラッグ** | なし | 不問 | **Window Level/Width 調整** | 左右:幅(Width), 上下:レベル(Level) |
| **中ボタンドラッグ** | なし | 不問 | **パンニング (Pan)** | ツールに関わらず画像を移動 |
| **ホイール回転** | なし | 不問 | **スライス移動** | 同期ON時は他ビューアも追従 |
| **ホイール回転** | Alt | 不問 | **ズーム (Zoom)** | 中心点基準の拡大縮小 |
| **ダブルクリック** | なし | 不問 | **WL/WW リセット** | DICOMタグのデフォルト値へ復帰 |

## 3. 3D ビューア マウス操作マトリクス (HOROS 完全準拠)

3D ビューアにおける操作は、3D空間内での直観的な幾何操作を目的とし、DCMView ツール状態に関わらず高速かつ物理的に同期する。

| 操作 | 実行されるアクション | 数学・制御的詳細 | 物理フィードバック |
| :--- | :--- | :--- | :--- |
| **左ドラッグ** | **3D 自由回転 (Rotation)** | 横移動 `dx` で Y 軸周り回転、縦移動 `dy` で X 軸周り回転。 | ボリュームモデル行列の回転クォータニオンをリアルタイム加算。 |
| **右ドラッグ** | **Window Level / Width 調整** | 左右ドラッグで窓幅 `WW` 変更、上下ドラッグで窓レベル `WL` 変更。 | **伝達関数テクスチャへのリアルタイム射影再描画**。左上のWL/WW数値も瞬時に変更。 |
| **中ボタン/ホイールクリック** | **スクリーン整合パニング (Pan)** | マウスの「上下左右」のドラッグ方向と、画面上の物体の移動方向を1:1で完全一致。 | **Up/Rightベクトル空間射影計算**：<br>$\Delta \text{Offset} = -dx \cdot R_{vol} + dy \cdot U_{vol}$<br>によってボリュームの中心オフセットを制御。 |
| **ホイールスクロール** | **ズームイン・アウト (Zoom)** | 投影空間のズーム倍率を変更。 | `zoom *= (1.0 - rotation * 0.1)` にてスケールを制御。 |
| **ダブルクリック** | **WL/WW & 視点リセット** | 視点角度を初期CT体軸断面位置へ戻し、WL/WW値をデフォルトの `1024/4096` にリセット。 | レンダラー初期マトリクスおよび伝達関数マッピングの完全復元。 |

## 4. キーボードショートカット一覧

### 4.1 ツールモード切替 (Single Key)
これらのキーを押下した瞬間、ビューアの `currentTool` が変更される。
- **W**: Window Level/Width ツール
- **Z**: ズームツール
- **P**: パンニングツール
- **M**: 長さ計測ツール
- **S**: セレクター (標準) ツール

### 4.2 2D プリセット WL/WW (テンキー/数字キー)
- **1**: Brain (WL 40 / WW 80)
- **2**: Bone (WL 300 / WW 1500)
- **3**: Lung (WL -600 / WW 1500)
- **4**: Soft Tissue (WL 40 / WW 400)
- **5**: リセット (Dicom Default)

## 5. フォーカス管理と同期の連鎖フロー (isKeyView)

Java Swing での実装において最も重要なのは、複数ビューア間でのアクティブウィンドウの特定と同期のタイミング制御である。

### 5.1 フォーカス取得と `isKeyView` 状態遷移
1. **マウスホバー**: マウスがビューア内に入ると一時的なフォーカス候補となる。
2. **クリック / アクション**: ビューアがクリックされるか、キー操作が行われた瞬間に `isKeyView` が `true` に遷移。
3. **同期送信（プロパゲーション）**:
   - 操作側ビューア (`isKeyView == true`) から、スクロール位置、ズーム比、WL/WW変化などの同期コマンド（`sendSyncMessage`）を発行。
   - 他の受信側ビューアは、`docs/UI/01-Viewer-Sync-Logic.md` に定義された同期フィルタ（Slab, Orientation 一致チェック）を通過した上で自動的に状態を同期。
4. **フォーカス喪失**: 別のビューアがアクティブになった場合、旧ビューアは `isKeyView = false` となり、コマンド送信元としての役割を終了。
